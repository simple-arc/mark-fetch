# md

turn any URL into clean Markdown — no ads, no clutter, just content.

────────────────────────────────────────

What it does

extracts the main content from any webpage and converts it into 
readable Markdown. Paste a link, get clean .md back. Download it or 
copy it.

No signup. No trackers. Just a bar and a result.

────────────────────────────────────────

How it works

[ URL ] → [ defuddle.md API ] → [ clean Markdown ]

The page uses the defuddle.md API to fetch and strip the page down to 
its core content.

────────────────────────────────────────

Features

  • one input — paste any URL
  • clean output — removes ads, nav, footers, scripts
  • download — save as .md file
  • copy-ready — markdown appears instantly
  • dark & minimal — black and white, no distractions

────────────────────────────────────────

Tech stack

  • HTML + CSS + vanilla JS
  • defuddle.md API

────────────────────────────────────────

Use cases

  • save articles for offline reading
  • feed content into LLMs (clean prompt input)
  • archive web pages as markdown
  • research & note-taking
