# md

> turn any URL into clean Markdown — no ads, no clutter, just content.

---

## About The Project

There are many ways to save web content, but most clutter it with ads, navigation, and scripts. **md** solves this by extracting the main content from any webpage and converting it to clean, readable Markdown.

Paste a URL, get a `.md` file. No signup. No trackers. Just a bar and a result.

**Live Demo:** [https://md.rip](https://md.rip)

---

### Built With

* HTML5
* CSS3
* Vanilla JavaScript
* [defuddle.md API](https://defuddle.md)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/yourusername/md.git
   ```
2. Open `index.html` in your browser
   ```sh
   open index.html
   ```
No build step. No dependencies. Just open and use.

---

## Usage

1. Paste any URL into the input field
2. Click "convert" or press Enter
3. View the clean Markdown output
4. Download as `.md` or copy the content

**Example:**
```
https://example.com/article → clean, readable markdown
```

## Features

- **One input** — paste any URL
- **Clean output** — strips ads, navigation, footers, scripts

- **Copy-ready** — markdown appears instantly
